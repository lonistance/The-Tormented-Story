## 备注：主角的孩子与性转废案资源

主角（凯尔）的孩子是**女儿**（名：艾琳【拟定】，Eilin），而非儿子；小说中所有相关表述（如第六卷"父女决斗"）以此为准。

原因：作者在制作 MOD 时，出于恶趣味制作了主角角色的少量"性转版"资源（废案）。决定写小说后，为避免破坏角色的文学艺术形象，"性转版"不适合由作者本人发布，因此将这批废案资源交给主角的孩子使用——她将作为（很可能不会推出的）第二个可玩角色存在。她进入高塔的动机很简单：**寻找父亲**。这意味着这个角色不会像 The Tormented 一样拥有完整的人物塑造（作者也需要休息一段时间）。
