# 章节冲突工程包（Chapter Conflict Engineering Package）

> **章节定位**：第三卷《战争之子》第七章（原第六章顺延，重构开篇以无缝衔接第六章结尾）  
> **拟定标题**：《你想死吗？》  
> **叙事视角**：第三人称限知视角（全镜头跟随凯尔）  
> **未来声音配额**：0 次（本章严禁使用任何未来声音/预叙旁白）

## 一、核心冲突要素明细

| 工程要素 | 具体参数与执行规约 |
|:---|:---|
| **核心人物** | 凯尔·阿伦（Kael Aren）、埃里安·索尔（Erian Sol，战场求生老兵/长腿医生） |
| **目标 (Goal)** | 凯尔：执意孤身翻越黑石梁斩杀溃逃残敌，以求彻底断绝后患，并向埃里安证明自己不是送死而是为了赢；<br>埃里安：用最现实粗鲁的手段把这个不知死活的年轻愣头青从鬼门关捞回来。 |
| **障碍 (Obstacle)** | ① 舍弃大部队独自行动，黑石梁地形险峻且敌暗我明；② 残敌中暗藏老辣断后伏兵，凯尔遭遇夹击受创坠入冰溪濒死；③ 埃里安尖锐刺骨的现实质问直击凯尔内心防御。 |
| **代价 (Cost)** | ① 凯尔肋下受贯穿性割伤、坠溪剧烈受冻窒息、违令脱队被罚马厩当值；② 凯尔“算无遗策、带队必胜”的虚荣认知被当头棒喝击碎，首次直面濒死无力的恐惧。 |
| **行动 (Action)** | ① **开篇无缝承接**：凯尔简短吩咐老卒带伤员回营，自己拔足只身扑入暮色密林追击残敌；② **追踪与中伏**：循血迹与折枝翻越黑石梁，在石坎后遭遇断后敌兵伏击，左肩受钝击、肋下受创，坠入深沟冰溪闭气潜伏；③ **埃里安佯兵相救**：埃里安在崖顶利用滚石与军营大嗓门虚张声势（“谷口堵死/二队跟上/弓手上崖”）吓退残敌，跳入溪中将冻僵的凯尔拽出；④ **石檐夜话对峙**：埃里安粗鲁敷药止血，两人爆发核心对话（“你想死吗？”／“我只是想赢。”／“战争里这两个经常没有区别。”）；⑤ **战后余波**：次日凯尔在马厩受罚刷马，傍晚排队盛满热汤无声递给埃里安。 |
| **后果 (Consequence)** | ① 凯尔保住性命但初尝鲁莽冒进的严酷代价；② 凯尔与埃里安正式结为生死之交（关系由第一章的功能型抢汤跃迁为情感型战友）；③ 埃里安成为军营中唯一敢刺破凯尔自欺幻觉的镜子。 |
| **伏笔/回收 ID** | **回收/兑现**：`FB-03-PURSUIT-TRAP`（第六章末按剑欲追的悬念在本章开篇直接兑现为翻梁中伏）、`FB-01-HUNT-EXP`（山林追踪痕迹）。<br>**埋设/强化**：`FB-03-ERIAN-TRUTH`（“想死与想赢没有区别”——贯穿卷三、卷四的自毁警钟）、`FB-03-ERIAN-STAND`（埃里安怕死却本能救人的行动，为第十四章凡人挡神埋设基石）。 |
| **三链行为 ID** | `BHV-015`（执意孤身翻梁追敌自语“我只是想赢”，将鲁莽送命与胜利等同；被点破后内心震颤但嘴硬自欺） |
| **称呼规则** | 限知视角跟随凯尔；埃里安称凯尔为“红印的小子”/“小子”；凯尔称埃里安为“长腿的”/“老兵”；严禁出现“死神”称谓。 |
| **误解机制** | **截断式/替换式误解**：<br>埃里安质问“你想死吗？战争里赢和想死经常没区别” → 凯尔内心第一反应不是反思冒进，而是咬牙认定“是因为我这次剑还不够快、地形没看清，再追半里我就赢了”，试图用技艺不足掩盖战略盲目。 |

## 二、红线指令与技术约束

### 1. “不合理但符合人物”强制指令
- **指令内容**：在冰溪中几乎冻僵窒息、肋下撕裂受创且全靠埃里安虚张声势才侥幸捡回一条命的极度狼狈情境下，面对埃里安“你想死吗”的痛斥，凯尔不仅不表达后怕或感激，反而死死咬紧牙关，固执地辩解“拿住领头的，河谷就太平了；再追半里我就赢了；这笔账很通”，用近乎蛮横的逻辑自欺来死守自己“为了保护同伴”的崇高幻象。

### 2. 细节预算与镜头控制
- **开篇承接镜头**：完全舍弃旧稿“第十三天牛栏起火”的突兀前置，直接从第六章结尾的暮色干沟切入——老卒呼喊回营，凯尔丢下一句“抬他走，我去去就回”，背影瞬间没入黑石梁阴影。
- **环境细节预算（严格控制为 3 个）**：
  1. 溪底冰冷刺骨的水流、水面上散开的缕缕暗红血丝与探来探去的矛尖；
  2. 崖顶滚落的碎石轰鸣与埃里安粗粝横蛮的吼声；
  3. 石檐下埃里安粗鲁按压伤口时发霉干布条的苦涩草药味。

### 3. 30% 删减预设标记（Pruning Targets）
- 彻底剔除旧版“前哨折两人、三十头牛被盗、副将点兵训话”等与第六章主因果脱节的冗长篇幅；
- 剔除任何对埃里安“大义相救”的拔高描写，突出其骂骂咧咧、怕死又手脚不停的粗鲁本能；
- 剔除对凯尔心理活动的过度解释，所有自尊受挫全由身体僵硬、咬牙、递汤无言等动作承担。
