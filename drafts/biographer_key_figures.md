# 关键他人档案卡（Key Figures Bible）

> **编制说明**：收录影响凯尔·阿伦（Kael Aren）命运轨迹的核心与关键人物档案。  
> **细节预算控制**：每张档案卡严格限定 **1～3 个最具辨识度的物理/习惯细节**，禁止泛化堆砌。  
> **红线原则**：严格执行 `STORY_BIBLE.md` 第 4 节、第 5 节及 `CHANGELOG.md` 既定约束。

## 核心人物档案

### 1. 艾德里安·瓦尔（Adrian Vale）
- **身份/代号**：流浪骑士 / 凯尔的第一位导师 / \"保护\"的定义者（\"三个普通男人\"之二）
- **阵营归属**：独立流浪者（前王国骑士）
- **登场卷章**：第二卷第一章《来自远方的陌生人》
- **退场方式**：第二卷第十四章《分别》（晨雾中驻马目送凯尔离去，和平隐退，于第五卷第十四章被凯尔回响念及）
- **核心欲望**：逃避杀戮过去的罪孽，以普通日常帮工赎罪，尽己所能保护一个无辜孩子不重蹈自己的覆辙。
- **对凯尔单向改变量**：
  - 赋予凯尔正规的步法、剑技与克制战斗雏形；
  - 赠予贯穿一生的【普通长剑】；
  - 埋下\"剑是为了保护而非证明\"与\"放下剑后仍然知道自己是谁\"的终生认知种子（凯尔用了一生才理解）。
- **辨识度细节（预算 3 项）**：
  1. **起茧而沉稳的双手**：挑水时极稳，但半夜梦游惊醒握剑时会渗满冷汗；
  2. **褪色磨损的旧羊毛斗篷**：下摆有粗糙但细密的修补针脚；
  3. **不善言辞的伺候动作**：凯尔生病时不发一言，只默默起身、煎药、掖紧被角。
- **核心台词**：
  - \"握紧，但别攥死。\"
  - \"剑不是用来证明自己的。我用它证明过——证明到最后，连名字都证明丢了。\"
  - \"教你剑，是让你有一天不需要剑。\"
  - \"艾德里安·瓦尔。\"（第二卷第十四章唯一一次报真名）
- **限知视角命名规则**：
  - 跟随凯尔视角：严格限定为【骑士】、【那个骑士】、【养父】、【他】，绝对禁止使用\"艾德里安\"或\"瓦尔\"；
  - 跟随自身视角：内心叙事仅用【他】，严禁自呼全名；
  - 凯尔口头称谓：终生未曾喊出\"父亲/爹\"（第二卷泉边那声未出口的\"爹\"保留为既成事实，但绝不补喊）；
  - 唯一真名出口例外：第二卷第十四章分别时原话自报。
- **红线禁区**：
  - 严禁写成全知全能的智慧老人；
  - 严禁发表超过三句的连贯哲理长篇大论；必须坚持\"做，不说\"；
  - 严禁在第二卷第十四章前让凯尔或旁白点破其真实姓名。

### 2. 埃里安·索尔（Erian Sol）
- **身份/代号**：军营老兵（逃兵） / \"长腿的医生\" / 绝境求生的普通人（\"三个普通男人\"之三）
- **阵营归属**：边境王国征兵步卒 / 战后归乡农人
- **登场卷章**：第三卷第一章《踏入战场》（晚餐抢汤登场）；第六章《你想死吗？》（追击相救确立深交）
- **退场方式**：第三卷第十二章《埃里安的离开》（厌战退伍还乡种地；第十四章挑战战神未死；第四卷第六章、第五卷第二章由后代转述其终老与遗言）
- **核心欲望**：在绞肉机般的战争中吃饱饭、保住性命、守住不滥杀与救治伤员的底线，最终回到老家种地。
- **对凯尔单向改变量**：
  - 充当凯尔在军营中唯一敢讲真话的镜子；
  - 用身体力行挡下屠杀降兵之举，守护了凯尔残存的善意底线；
  - 以最弱之躯挑战神明且被战神铭记的事实，成为击碎凯尔\"强者才能得到神明承认\"执念的终极铁证。
- **辨识度细节（预算 3 项）**：
  1. **洗得发白褪色的急救布卷**：挂在腰间，不论敌我，遇伤兵便撕下包扎；
  2. **逃跑比冲锋快的长腿与碎嘴习惯**：抢饭抢汤动作极快，边吃边骂娘或自嘲怕死；
  3. **挡在屠刀前剧烈颤抖的手**：面对杀戮与神明时双腿打颤，但至死没有后退一步。
- **核心台词**：
  - \"战争里，赢和想死这两个东西经常没有区别。\"
  - \"你不是为了胜利，你是在证明。\"
  - \"我杀了十年才明白，我杀死的每一个敌人，都留下一个新的敌人。\"
  - \"我怕。可我救的人，在那边。\"（第三卷第十四章面对战神）
  - \"我这辈子，就勇敢过一次。一次，够了。\"（第五卷第二章后代转述遗言）
- **战神记忆伏笔链**：
  - 第三卷第十四章：战神对埃里安说：\"我记住你了。\"（埃里安未解其意，凯尔不知情）；
  - 第四卷第六章：后代对凯尔说：\"他败给了神明。但是他没有背叛自己。\"；
  - 第四卷第七章：战神对凯尔说：\"我记住过一个凡人。不是你。\"；
  - 第五卷第二章：后代转述：\"那一天，他忘了跑。\"
- **红线禁区**：
  - 严禁写成幻灭的崇高理想主义者；
  - 严禁说出\"我虽然害怕但我要做\"等自我升华、自我剖析台词；
  - 严禁第三卷出现任何暗示他与神明有神秘羁绊的段落（神明唯独记住他是因其弱小却敢挡的凡人性）；
  - 对神明话题严禁表现出异常敏感，必须与普通粗鄙士兵同等对待（怕、远、不讨论）。

### 3. 瑟琳（Therin，凯尔之母）
- **身份/代号**：流落边境的黑暗精灵族人 / 母亲
- **阵营归属**：烬石部落边缘归附者
- **登场卷章**：第一卷第一章《不祥的诞生》
- **退场方式**：第一卷第七章《离别故乡》（门后压抑哭泣目送儿子离去，第六卷重回部落已化为岁月废墟）
- **核心欲望**：在充满戒备与敌意的部落中庇护虚弱的混血儿子平安长大。
- **对凯尔单向改变量**：
  - 凯尔生命中第一个无条件爱他的人；
  - 赋予凯尔黑暗精灵敏捷与夜视的天赋血脉；
  - 制作并赠送贯穿全书七卷的【暗精灵护符】。
- **辨识度细节（预算 2 项）**：
  1. **暗夜中微光的深色眼眸**：带着克制隐忍的悲悯，轻哼无词的暗精灵摇篮曲；
  2. **粗糙厚布缝制的小巧护符**：针脚细密，内里不装任何石头，只装入未出口的祝福。
- **核心台词**：
  - \"活着，然后回家。\"
  - \"你值得被爱。\"（缝入护符密语）
  - \"有些事，剑管不了。\"
- **护符贯穿规则**：
  - 卷一：缝制并戴上；卷二：贴身携带；卷三：战火中仍在；卷四：因杀戮麻木而遗忘携带缘由；卷五：妻子问起答\"母亲给的\"；卷六：浩劫后重新握紧手心；卷七：随身带入尖塔。
- **红线禁区**：
  - 严禁将护符描写为具有魔法防御或奇幻属性的道具；
  - 严禁写成怨恨族人的复仇母亲。

### 4. 加尔（Garr，凯尔之父）
- **身份/代号**：烬石部落普通人类猎手 / 父亲（\"三个普通男人\"之一）
- **阵营归属**：烬石部落
- **登场卷章**：第一卷第一章《不祥的诞生》
- **退场方式**：第一卷第六章《预言的误解》（与凯尔长谈后沉默，终老于部族岁月）
- **核心欲望**：以沉默的劳作和猎物份额换取部族对异族妻儿的容忍，维系家庭生存。
- **对凯尔单向改变量**：
  - 给予凯尔人类骨骼的耐力与基础山林追踪常识；
  - 成为凯尔一生唯一一次正面获得血亲对印记的无罪背书（\"你什么都没做错\"）。
- **辨识度细节（预算 2 项）**：
  1. **满是松脂与冻裂伤口的粗大猎手手掌**；
  2. **沉默分猎物的习惯**：打完猎默默把最肥厚的一块放在长老门槛外，不发一言。
- **核心台词**：
  - \"你什么都没做错。\"
  - \"下回，叫我。\"
  - \"山不说话，但它会回答。\"
- **红线禁区**：
  - 严禁写成\"为儿子单挑整个部落抗争到底的悲壮英雄父亲\"（一生仅与长老吵过一次架）。

### 5. 战争神（赫拉格 Herrag【拟定】）
- **身份/代号**：司掌战争本质的古老神明 / 凯尔前半生的镜子与宿敌
- **阵营归属**：神明
- **登场卷章**：第三卷第十四章（战埃里安）；第十六章（初战凯尔）；第四卷第七至十二章（再战、断臂、施咒）
- **退场方式**：第四卷第十二章施加不死诅咒后离去；第七卷荒疫爆发成为受灾神明之一
- **核心欲望**：行使纯粹的战争法则，蔑视为虚荣和自证而来的喧嚣，见证凡人在绝境下的纯粹意志。
- **对凯尔单向改变量**：
  - 两次正面粉碎凯尔对\"力量即认可\"的傲慢认知；
  - 斩臂后施加【永恒不死诅咒】，彻底改变凯尔生命形态并将其推入死神深渊。
- **辨识度细节（预算 2 项）**：
  1. **如风暴残垣般冷寂的巨神重铠**：残破却散发如铁锈与古老战场硝烟的气息；
  2. **被斩断的右臂断口**：不流血泪，仅有如岩浆凝固般的神性残迹与平静冷眼。
- **核心台词**：
  - \"你的剑很锋利。但你的心太吵。\"
  - \"又一个寻求荣耀的人。\"
  - \"我记住过一个凡人。不是你。\"
  - \"你赢了一场战斗，却仍然不知道自己为何挥剑。\"
- **红线禁区**：
  - 严禁写成傲慢无脑、视凡人为蝼蚁的扁平邪神；
  - 其愤怒从来不是因为断臂败北，而是因赢家凯尔居然对战争与胜利的本质一无所知；
  - 神明立场不可擅改。

### 6. 米拉（Mira【拟定】，凯尔之妻）
- **身份/代号**：乡村裁缝 / \"凯尔\"这个名字的守护者 / 凯尔凡人生活的救赎者
- **阵营归属**：橡木村（后证实为烬石故地）平民
- **登场卷章**：第五卷第七章《妻子的出现》
- **退场方式**：第六卷第十四章（倚门目送凯尔离村）；第十六章通过遗留的【自制普通项链】确认退场
- **核心欲望**：与笨拙的凯尔过平凡日子，用缝针、热汤与理解为凯尔抚平一生的战火伤痕。
- **对凯尔单向改变量**：
  - 几十年后重新唤醒\"凯尔\"这一名字，击碎\"死神\"面具；
  - 让凯尔体验到无需用剑证明也能被全然爱着的凡人幸福；
  - 其遗留项链成为第七卷支撑凯尔承担责任的终极羁绊。
- **辨识度细节（预算 3 项）**：
  1. **带着顶针与针线划痕的纤细手指**：轻拉凯尔衣袖遮盖胎印；
  2. **温和带笑的微翘眼角**：看凯尔劈柴烧糊饭时从不嘲笑，只轻声叹气；
  3. **颈间常年佩戴的粗糙项链**：非昂贵宝石，纯为凯尔亲手敲打磨制的普通小饰物。
- **核心台词**：
  - \"疼吗？\"
  - \"我叫你凯尔。\"
  - \"凯尔，吃饭了。\"
  - \"你已经保护我们很多年了。\"
- **妻子死亡特别规则（最高级红线）**：
  - **绝对禁止**凯尔确认其死亡；
  - **绝对禁止**任何角色口头或书面确认其死亡；
  - **绝对禁止**出现尸体、骸骨或直接死亡现场描写；
  - 仅允许通过：凯尔寻找落空、幸存者转述\"没找到她，只找到这个\"、遗留普通项链、环境废墟、凯尔身体反应（双膝跪地、手心攥出血印）呈现。

### 7. 艾琳（Eilin【拟定】，凯尔与米拉之女）
- **身份/代号**：凯尔之女 / 剑道传承者 / 全书主题终极答案的践行者
- **阵营归属**：村落平民 / 战乱撤离者
- **登场卷章**：第五卷第十章《成为父亲》
- **退场方式**：第六卷第十三章《送孩子离开》（决斗后带剑踏上护人之路，下落未明；第七卷成为凯尔入塔寻觅的悬念牵挂）
- **核心欲望**：保护弱小、让陷入战火与恐惧中的人们重获信任，寻找失踪的父亲。
- **对凯尔单向改变量**：
  - 让凯尔在笨拙父爱中学会幽默与放下执念；
  - 在决斗中让凯尔首次主动认输偏转剑锋，教会父亲\"爱与宽恕也是武器\"；
  - 代替年轻时的凯尔走上了\"剑是为了保护与信任\"的正确道路。
- **辨识度细节（预算 2 项）**：
  1. **神似母亲的明亮眼眸与随身携带的短木剑**：练习时重心极稳；
  2. **吃甜食时沾着糖渣的嘴角与擦伤的虎口**。
- **核心台词**：
  - \"剑不是为了赢，是为了保护。\"
  - \"还有比剑更强大的东西——让别人相信你。\"
  - \"父亲，我做对了吗？\"
- **红线禁区**：
  - 明确为**女儿**（绝非儿子）；
  - **严禁写成女性版凯尔**（凯尔为自证而战，艾琳为护人承担责任）；
  - 具有自己的性格缺陷（过度承担、把所有人背在身上）；
  - 进入尖塔/行动的初始动机纯粹是**寻找父亲**，绝不可一开始就背负\"拯救世界\"的宏大叙事。

### 8. Neow
- **身份/代号**：蓝肤古老存在 / 尖塔引路人 / 契约交易者
- **阵营归属**：未知高维（尖塔/腐化生态核心关联者）
- **登场卷章**：第七卷第四章《Neow 的注视》（远景）、第五章《第一次见面》
- **退场方式**：贯穿第七卷末并衔接游戏开局（伫立于尖塔大门前迎接立约者）
- **核心欲望**：寻找永恒不死、战技绝伦的凡人战士作为工具，进入尖塔解决自身困境。
- **对凯尔单向改变量**：
  - 提供了解除不死诅咒的契约条件；
  - 见证凯尔从追求证明的传奇蜕变为自我命名的\"受刑者\"。
- **辨识度细节（预算 2 项）**：
  1. **如深海般幽邃冰冷的蓝色躯体与发光巨眸**；
  2. **平缓无波澜却暗藏交易筹码的低语声调**。
- **核心台词**：
  - \"你还想死吗？\"
  - \"我需要一个无法死亡的战士。\"
  - \"杀死荒疫源头，我可以解除你的诅咒。\"
  - \"你不需要相信我。你只需要相信你自己。\"
- **Neow 书写三大禁区（不可由任何角色/旁白证实）**：
  1. 荒疫实际上与 Neow 密切相关；
  2. Neow 嫉妒造物主；
  3. Neow 利用爬塔者解决自身危机。
- **红线禁区**：
  - 严禁表现为纯粹善良、无私救世的神明；其所有行为与对话必须表现为诱惑与冷酷的利益交换。
